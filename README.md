桌面便签 · 待办清单
一款贴在屏幕边缘的 Windows 悬浮便签，桌面、网页、手环共用同一份待办清单。
简介
桌面便签 · 待办清单 是一款轻量级的跨端待办工具。它不做复杂的项目管理，只解决一件小事：把今天要做的事记下来，做完打一个勾。
在 Windows 上，它是一张吸附在屏幕边缘的无边框小窗。平时自动收起，只在屏幕边留一条彩色小把手；鼠标滑到边缘，它就展开。可以添加 / 完成 / 双击修改 / 删除待办，顶部有进度条和完成计数，未做完的事支持定时通过 Windows 通知中心提醒。外观上提供 6 套主题、液态玻璃质感、3 档宽度、5 档不透明度，以及贴边吸附、自动隐藏、置顶、折叠为标题栏、开机自启等行为选项。
同一份清单会出现在网页版和小米手环 9 Pro 上：网页是纯静态 PWA，iPhone / 安卓浏览器打开即可使用，可「添加到主屏幕」，断网时靠 Service Worker 仍可查看；手环端是 Vela 快应用，336×480 小屏做了离线优先，联网后自动补同步。三端通过 Supabase 同步，Realtime 实时推送之外还有定时轮询兜底，网络不稳时数据最终也会一致。
账号按邮箱注册登录，各账号清单通过行级权限隔离。多账号可一键切换：登录过的账号经 Windows 系统加密保存在本机，在设置页点一下即可换过去，无需反复输密码。所有外观、行为、提醒等偏好设置只存在本机，不上传云端。

核心功能
- 桌面小组件：四边吸附、自动隐藏 / 滑出唤出、置顶、折叠为标题栏、固定显示、开机自启
- 外观：6 套主题（柠檬黄 / 薄荷绿 / 晴空蓝 / 樱花粉 / 暗夜灰 / 素雅白）、液态玻璃、宽度与不透明度可调
- 待办：添加、完成、双击编辑、删除、进度条与完成计数、完成后自动下沉
- 提醒：未完成任务定时通知，间隔 5 / 10 / 15 / 30 / 60 分钟，或自定义 1–240 分钟
- 设置：左侧导航 7 组（外观 / 行为 / 提醒 / 账户 / 云同步 / 数据 / 关于）；菜单、托盘、设置页三处改动实时一致
- 账户：邮箱注册登录、数据隔离、本机加密保存多账号、一键免密切换、移除凭据
- 同步：Realtime 实时推送 + 桌面 15 秒 / 网页 8 秒轮询兜底
启动
1. 安装版（推荐，启动最快）：双击 dist-rebuild-1.1.7/bianqian-1.1.7-setup.exe，向导式安装，自动创建桌面与开始菜单快捷方式。装好后原地运行，不重复解压。
2. 便携版：双击 dist-rebuild-1.1.7/bianqian-1.1.7-portable.exe，单文件免安装，可拷到任何 Windows 电脑。注意便携版是自解压包，每次启动都会解压到临时目录再运行，启动比安装版慢；换新版前要先退出正在运行的便签，否则单实例锁会让新窗口静默退出。
3. 双击 启动便签.vbs（无黑窗）或 启动便签.bat：优先调用已安装版本，找不到时回退到源码运行；命令行 npm start 亦可。
首次启动会看到一张示例便签，随后自动收起到屏幕边缘，只留一条彩色小把手。
未签名的 exe 被移到新位置后，Windows Defender / Smart App Control 首次会做云信誉检查，首开可能多等几秒，之后会缓存。

设置窗口
点标题栏齿轮或右键菜单「设置…」打开独立窗口，左侧导航分 7 组：
- 外观 / 行为 / 提醒：主题、宽度、不透明度、液态玻璃、置顶、吸附位置、自动隐藏、完成后下沉、开机自启、提醒频率等
- 账户：当前账号、本机账号列表（点「切换」免密换号、点「移除」删凭据）、添加账号（邮箱 + 密码 + 登录 / 注册）
- 云同步：开关、连接状态、实时推送状态、Realtime 配置 SQL、打开数据目录
- 数据：便签标题、清除已完成、清空全部事项（会同步删除云端对应数据）
- 关于：版本、检查更新、关于便签、刷新状态、重置首次登录提示、退出便签
在右键菜单或托盘里改的开关，会实时同步到设置页显示；反过来也一样。
多账号一键切换
登录过的账号保存在 %APPDATA%\便签\accounts.json：密码用 Windows 系统加密（DPAPI，绑定当前 Windows 用户）后存本机，不上传、不明文。每个账号第一次需要用密码登录一次才会被记住，之后点列表里的「切换」即可直接换过去，不用重输密码。退出登录后重启会重新弹出登录框。
网页版与手环端
- 网页 / PWA：pwa/ 是纯静态站点，根目录含 index.html、app.js、config.js、styles.css、manifest.webmanifest、sw.js、_headers 与 vendor/supabase.js，无需构建命令，整个目录上传到 Cloudflare Pages 即可。每次改代码要同步给 sw.js 升缓存版本号，否则浏览器一直读旧文件；_headers 已让 sw.js 等关键文件不被 CDN 缓存。
- 小米手环 9 Pro：vela-bianqian/ 为 Vela 快应用，用 AIoT-IDE / AstroBox 侧载 rpk。手环端禁用了会触发原生崩溃的 PUT/PATCH 与冷启动连发请求，完成事项走单次 POST 调 set_todo_done RPC；iPhone 配对时快应用联网受限，因此做了离线优先，联网后自动补同步。
数据与设置
- 待办内容与本机设置：%APPDATA%\便签\notes.json
- 云同步会话：%APPDATA%\便签\auth-session.json；云端连接配置：cloud-config.json（只含 URL 与公开密钥）
- 多账号凭据：%APPDATA%\便签\accounts.json（密码经系统加密）
- 云端表：public.todos，按 user_id 用 RLS 隔离；需要在 Supabase SQL Editor 执行一次 supabase-schema.sql（含把 todos 加入 supabase_realtime 与 replica identity full）
- 托盘图标在屏幕右下角：左键 = 显示 / 收起，右键 = 菜单
- 单实例运行：重复启动只会把已有便签唤出
更新系统（基于 GitHub，可选启用）
便签内置零依赖的更新检查：直接读取 GitHub 仓库最新 Release，发现新版本时在 Windows 通知中心提示，点击前往下载。
- 在 main.js 顶部把 GITHUB_REPO 设为 "用户名/仓库名" 即启用，留空则完全禁用。
- 发布流程：改 package.json 的 version → npm run build → 在 GitHub 打形如 v1.1.7 的 tag 并发布 Release，把 bianqian-<版本>-setup.exe 与 bianqian-<版本>-portable.exe 作为 assets 上传。tag 必须带 v 前缀且与版本号一致。
- 启动 8 秒后静默检查，有新版才通知；菜单「检查更新…」可手动触发。
- GitHub 资产名建议用英文（中文名容易在 GitHub 编辑框里塌缩成同名导致上传冲突）。
v1.0.0 及更早版本用的是旧更新方案，无法感知 GitHub Release，需手动安装一次新版；之后即可自动更新
